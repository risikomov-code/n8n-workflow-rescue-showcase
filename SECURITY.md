# Public Showcase / Security Boundary

This repository is intentionally **not** a deployable n8n workflow or production backup.

## Public

- rescue methodology
- failure categories
- high-level troubleshooting architecture
- validation principles
- regression-testing concepts
- non-sensitive portfolio narrative

## Private

- workflow exports
- node configuration
- credentials
- API keys and tokens
- webhook URLs
- provider account identifiers
- production infrastructure
- customer data
- prompts
- exact payloads
- internal file paths
- full state schemas
- cost formulas
- routing and retry logic
- execution logs

No production secret or customer information should ever be committed to this repository.
